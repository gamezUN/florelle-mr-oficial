# FLORELLE MR. — sitio web
Sitio estático para catálogo y solicitudes de pedido en Cartagena, Colombia.

## Funciones
- Catálogo con 15 referencias, precios en COP, búsqueda y filtros.
- Sección independiente de bouquets de quinceañera.
- Adicionales y formulario con cálculo estimado de productos y anticipo del 50%.
- Fecha mínima de entrega: dos días a partir de la fecha actual.
- Opción de recoger o solicitar domicilio en Cartagena.
- Solicitud prellenada por correo a Maryricardoquintero@gmail.com.
- Enlaces a Instagram y TikTok. No se incluye WhatsApp.

## Límites reales de esta versión
- El formulario abre un correo del visitante; no guarda pedidos en una base de datos ni confirma reservas.
- No hay panel administrativo, calendario sincronizado, control de inventario ni cobro en línea.
- El costo del domicilio se cotiza según ubicación y no se calcula en el sitio.
- Las fotografías originales del catálogo PDF aún deben incorporarse como archivos del repositorio. Se evitó usar fotografías genéricas que pudieran representar productos incorrectos. Los elementos florales de esta versión son recursos gráficos decorativos, no fotos de producto.
