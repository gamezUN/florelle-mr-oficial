# FLORELLE MR. — Sitio web

## Archivos
- `index.html`: estructura y contenido de la página.
- `style.css`: identidad visual y diseño adaptable.
- `script.js`: catálogo, filtros, búsqueda, selección de producto y vista previa del formulario.

## Cómo abrir
Abre `index.html` en un navegador. Para editarlo, abre la carpeta completa en Visual Studio Code.

## Importante antes de publicar
Esta entrega es un prototipo front-end funcional. El formulario calcula una vista previa, pero NO envía pedidos ni guarda reservas en un servidor. Para operar en producción hay que conectar una base de datos, autenticación y un servicio de notificaciones.
La sección de pagos está deliberadamente pendiente y no procesa transacciones.
Las fotografías son referencias visuales temporales; deben sustituirse por fotografías autorizadas del catálogo real de FLORELLE MR.
El logotipo está representado provisionalmente como un wordmark tipográfico porque no se adjuntó el archivo original del logo. Sustituirlo por el logo oficial cuando Mariangel lo comparta.
El catálogo contiene los productos y precios extraídos de la información compartida; verificar cada fotografía, descripción y precio con el negocio antes de publicar.
No se incluye WhatsApp. Instagram y TikTok enlazan a los perfiles compartidos.
